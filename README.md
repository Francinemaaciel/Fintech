# 💼 Fintech - Página de Login

Este é um projeto simples de uma **página de login** desenvolvida com **HTML** e **CSS**. O objetivo é criar uma interface limpa e funcional para um sistema de login em uma fintech.

## 💡 Objetivo

O objetivo deste projeto é criar a página inicial de login de uma aplicação de fintech, com campos para o usuário inserir suas credenciais, como e-mail e senha. O layout é responsivo e foi projetado para ser simples e intuitivo.

## 📋 Funcionalidades

- Formulário de login com campos para e-mail e senha
- Layout responsivo para dispositivos móveis e desktops
- Design minimalista e de fácil navegação

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Para a estrutura da página
- **CSS3**: Para o estilo e layout responsivo (usando Flexbox e Media Queries)

## 🚀 Melhorias Futuras

- Implementar validação de campos com **JavaScript**
- Adicionar animações e transições com **CSS**
- Criar integração com back-end para autenticação real
- Personalizar a página com elementos gráficos como logo e ícones
